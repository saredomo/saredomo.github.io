日本語English

このポリシーは、「されども」（以下「私たち」）が、自分たちの作品を自分たちのアカウントに投稿するために使う社内ツール saredomo-publisher と、このウェブサイトでの情報の扱いを説明するものです。

1. saredomo-publisher について

saredomo-publisher は、私たちが制作した記事のお知らせや短い動画を、人間が1件ずつ確認・承認したあとで、私たち自身のアカウント（YouTube・Instagram・Facebook・Threads・X。TikTok は人の手で投稿）に投稿するための社内ツールです。一般には公開しておらず、私たち以外の人がログインしたり使ったりすることはありません。

2. YouTube API サービスの利用

saredomo-publisher は YouTube API サービスを使って、私たちの YouTube チャンネルに動画をアップロードし、カバー画像を設定し、必要な場合に私たち自身の動画を削除します。

  • YouTube API サービスを使う機能を利用することで、YouTube 利用規約に同意したものとみなされます。
  • Google による情報の扱いは Google プライバシー ポリシーをご覧ください。

3. 扱う情報

  • 認証情報：私たち自身のアカウントにアクセスするためのトークン（OAuth のリフレッシュトークン、ページ用のアクセストークンなど）。
  • 投稿の記録：私たちが投稿した動画・投稿の ID、URL、投稿日時、成否。
  • 反応の数字：私たち自身の投稿の表示回数・いいね数などの集計値（X・Threads・Facebook）。YouTube の数字は現在取得していません。

私たちは、私たち以外の人の個人情報やアカウントの情報を YouTube API サービスやほかの API から取得・保存しません。このウェブサイトは Cookie やアクセス解析を使っていません。

4. 使い方と共有

上の情報は、投稿の実行、二重投稿の防止、誤った投稿の削除、次の制作のふり返りのためだけに使います。第三者に販売・提供・共有することはありません。

5. 保存と削除

  • 認証情報は、GitHub の暗号化されたシークレットにだけ保存し、ファイルやログには書きません。
  • 投稿の記録は、非公開の GitHub リポジトリに保存します。YouTube API サービスから得たデータは、私たちの動画の ID と URL だけを保存し、それ以外を保存する場合は、YouTube API サービスのデベロッパー ポリシーが定める期間（30日）を超えて、更新せずに保持しません。
  • ツールの利用をやめるときは、認証情報を削除し、保存した記録も削除します。

6. アクセスの取り消し

saredomo-publisher に与えた Google アカウントへのアクセスは、Google のセキュリティ設定（サードパーティ アクセス）からいつでも取り消せます。Meta（Instagram・Facebook・Threads）へのアクセスは、各サービスの「アプリとウェブサイト」の設定から取り消せます。

7. 変更とお問い合わせ

このポリシーを変更するときは、このページを更新し、日付を改めます。お問い合わせは saredomoai@gmail.com までご連絡ください。

Privacy Policy (English)

Saredomo — small AI experiments in everyday life. Effective October 3, 2026.

This policy explains how “Saredomo” (“we”) handles information in saredomo-publisher, our internal tool for posting our own work to our own accounts, and on this website.

1. About saredomo-publisher

saredomo-publisher is an internal tool. After a person on our team reviews and approves each item, it posts our own article announcements and short videos to our own accounts on YouTube, Instagram, Facebook, Threads and X (TikTok is posted by hand). It is not offered to the public, and no one outside our team signs in to or uses it.

2. Use of YouTube API Services

saredomo-publisher uses YouTube API Services to upload videos to our YouTube channel, set their thumbnails, and delete our own videos when needed. By using features that rely on YouTube API Services, you agree to be bound by the YouTube Terms of Service. See the Google Privacy Policy for how Google handles information.

3. Information we handle

  • Credentials for our own accounts (OAuth refresh tokens, page access tokens).
  • Post records: IDs, URLs, times and results of the videos and posts we publish.
  • Aggregate metrics for our own posts (views, likes, etc. on X, Threads and Facebook). We do not currently collect YouTube metrics.

We do not collect or store personal information or account data of anyone else through YouTube API Services or any other API. This website uses no cookies or analytics.

4. Use and sharing

We use this information only to publish posts, prevent duplicate posts, delete mistaken posts, and review our work. We do not sell, provide or share it with third parties.

5. Storage and deletion

Credentials are stored only in encrypted GitHub secrets and are never written to files or logs. Post records are kept in a private GitHub repository. From YouTube API Services we store only the IDs and URLs of our own videos; any other YouTube API data will not be kept for more than 30 days without being refreshed, as required by the YouTube API Services Developer Policies. If we stop using the tool, we delete the credentials and the stored records.

6. Revoking access

Access granted to saredomo-publisher can be revoked at any time via the Google security settings page. Access to Meta services can be removed in each service’s “Apps and websites” settings.

7. Changes and contact

We will update this page and its date when this policy changes. Contact: saredomoai@gmail.com.
